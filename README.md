# 江西农网视频兼容性转换工具

一个仅做一件事的 Windows 工具：把多个 H.265/HEVC 视频转换为兼容性更好的 H.264 MP4。

- 支持批量添加视频或扫描文件夹
- 默认输出到原视频目录下 `H264_转换完成`，不改动原文件
- 可选择清晰度：CRF 18 / 20 / 23
- 保留原有音频；自动处理进度、取消和同名文件
- 打包版本会内置 FFmpeg，因此双击 `.exe` 就可用

## 下载

请前往本仓库的 [Releases](../../releases) 下载最新版 Windows EXE。

## 开发者构建

先把 Windows 版 `ffmpeg.exe` 放到本目录，再运行：

```powershell
.\build.ps1
```

输出文件：`dist\H265转H264批量转换器.exe`。

FFmpeg 的具体授权取决于所使用的二进制发行版；分发时请一并保留其许可证信息。
